# Android 参考与本轮改进

参考项目：[liuys19940507/codex-android](https://github.com/liuys19940507/codex-android/tree/8227b6b55c635b74ff9804ff39043c81de0593ca)，固定参考提交 `8227b6b`。本项目继续使用 SwiftUI 和 Windows 桥接，按其交互与阅读方式独立实现。

| 能力 | iOS 实现 |
| --- | --- |
| 多项目列表 | Windows 可开启 `discoverProjects: true`，按同一个 Codex 数据目录下已有会话的工作目录发现项目；全部项目、目录筛选、搜索和分页均保留。静态配置模式仍为默认 |
| 会话接管 | 共享 app-server 中的 CLI 与手机可以共同控制同一轮次。会话工具栏可刷新历史并重新连接；返回任务列表释放手机自己的订阅 |
| 独立 CLI 占用 | 显示最新历史和只读说明，保留草稿；退出电脑独立会话后点手机刷新。不会通过刷新抢占另一个进程的文件写入锁 |
| 任务阅读 | 用户消息气泡、助手 Markdown、标题、表格、列表与行内代码；按轮次折叠处理过程，最终回复直接显示 |
| 工具与过程 | 推理摘要、计划步骤、命令、状态、耗时、退出码与子任务入口；审批和问题保留独立操作区域 |
| 代码与终端 | 代码语言标记、原文复制、长输出末尾预览、完整视图；未闭合代码块保留提示 |
| 文件差异 | 按文件展示新增/删除行数、重命名和二进制提示，彩色 patch、完整视图、原文复制及不完整 hunk 提示 |
| 输入 | 底部固定编辑器、自动增高与键盘收起；常用指令和消息可追加到草稿，由本人明确发送 |
| 状态恢复 | 保留配对、Keychain、草稿、操作 UUID、事件游标与前后台恢复；刷新不会重发输入或审批 |
| 模型设置 | 使用服务实际返回的模型及推理选项，作用于之后新建的任务；当前会话沿用电脑配置 |

这些功能的自动检查、安装包与手机验证分别记录在[本轮验证记录](validation/conversation-experience.md)。自动测试通过不能代替实际覆盖安装与手机操作验证。

本轮不扩展 Android 项目的插件/应用管理、任意远程文件操作、图片上传与预览、队列及尚未验证的 MCP/权限操作。Markdown 图片显示占位符；链接只在本人点击 HTTP/HTTPS 地址时交给系统打开。按已确认方案继续不做锁屏远程推送。

渲染使用 [MarkdownUI 2.4.1](https://github.com/gonzalezreal/swift-markdown-ui/tree/2.4.1)，依赖图由 `ios/Package.resolved` 固定。完整第三方许可证随 App 打包，可在“设置 → 开源许可”查看。
