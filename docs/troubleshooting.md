# 运行排查

| 现象 | 检查方式 |
| --- | --- |
| Sideloadly Start 灰色 | 确认 iDevice 已显示手机、Apple ID 非空、左侧 IPA 名称不是 `<none>`；点击 IPA 图标重新选文件。不要卸载手机旧版。 |
| 设备连接不稳定 | 保持解锁，检查 USB 线和接口。已有 USB 配对后可按 Sideloadly 官方步骤在 iTunes 启用 Wi-Fi 同步；EasyTier 不替代 Apple 配对。 |
| App 连接失败 | 确认两端 EasyTier 在线、Windows 未休眠，桥接监听 `10.147.21.2:8391`。防火墙规则只允许私有网段。检查本机服务，不把令牌放入 URL。 |
| HTTP 可连，任务同步失败 | 区分 `/v1/info` 成功与 WebSocket 成功，检查会话“重新同步”的结果和桥接日志；不反复发送输入来测试网络。 |
| 看不到已有任务 | 必须从项目的 `Start-CodexRemote.ps1` 入口连接同一个共享 app-server，并且工作目录在 Windows 允许项目列表中。普通独立 CLI 的任务不会自动接管。 |
| 接入时前半段文字缺失 | 上游 0.167.0 在生成中途加入时不返回此前文字；显示“部分输出”，结束后完整消息会替换补齐。取消后未取得完整消息会保留不完整提示。 |
| 指令结果不确定 | 查看任务实际状态并使用“核对结果”；超时不会自动重发输入、创建或审批。新建部分成功时可打开已创建会话。 |
| 审批按钮禁用 | 先完成同步，检查轮次是否变化、CLI 是否已经处理、服务端是否支持该请求。未知格式在 Windows CLI 处理。 |
| 编辑连接时令牌为空 | 已保存令牌不会回显。地址不变时留空保留原令牌；修改地址需明确填写新令牌。 |
| 七天后应用打不开 | 用原账号和相同 Bundle ID 重新签名覆盖安装；检查实际签名工具结果。后台进程存在不代表续签成功。 |

Windows 休眠、断电或网络中断会影响远程连接。桥接可以独立重启，但停止共享 Codex app-server 可能影响运行任务；先核对任务与进程归属。
